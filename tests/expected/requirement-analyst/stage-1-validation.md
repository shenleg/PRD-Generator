# 阶段 1 校验参考清单

本文是规格 9.6 的机械规则映射，不包含模型自行生成的业务参考答案。业务黄金依据另见已获用户确认的 `high-low-voltage.review.md`。

- [ ] 规则 1、3：先格式后关系，错误输入不能导致内部字段访问异常；诊断保留字段位置和最近的条目编号。
- [ ] 规则 2：同需求编号唯一，来源也不能重复；只认可实际提供的本需求或关联需求中的编号。
- [ ] 规则 4：只限制就绪度的上界，不把 not_ready 判成校验失败；遵守研发 P1 例外。
- [ ] 规则 5、6：只有 active 的关联假设、决策有效，不能使用撤销记录关闭问题。
- [ ] 规则 7：来源非空针对 active 通用条目，问题没有被强行加上不存在的 sources 字段；清单和来源引用均检查。
- [ ] 规则 8：校验器只诊断，不自动改状态；待重评条目与已废弃问题可保留旧引用。
- [ ] 规则 9：unknown 不伪造依据；已作出的技术判断必须具备规定信息；研发问题不得错指产品问题。
- [ ] 规则 10：矛盾关联必须是当前需求中存在的问题。
- [ ] 规则 11：过期单独 warning，其他违规使整体 fail，不能因过期而忽略硬错误。
- [ ] CLI 标准输出为一个可解析 JSON 对象，退出码 pass=0、warning=1、fail=2，文件错误不泄漏 traceback。
- [ ] 校验过程只读，不更新原文、结果、来源清单或其他分析文件。
