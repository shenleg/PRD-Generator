# RA-11：新版文档

验证目标：逐项比对新增、删除、修改和未变内容，只重评变化及依赖项。

## 输入

第二样例原文及其实际分析。随后提供独立 v2 原文，变化完全按已审核参考 4.3：删除权限改为创建者和管理员；上限 1000 改 5000 并删除超量全部导出句；新增导出操作日志。其余原文保持。

## 预设回答

只通知“这是新版需求文档，请对照更新”，不替模型指出差异，不提供操作日志具体字段、保存期或实现方案。

## 核对清单

- [ ] 实际输出逐项 diff，含新增/删除/修改/未变，精确引用新旧位置。
- [ ] 只改变化及依赖项；未变目标、其他需求的来源/内容/状态不漂移。
- [ ] 新版保存为新 SRC，旧来源、旧正文和事件仍可追溯。
- [ ] 相关已关闭问题先重开并解释原因；若新版能明确解决，则在后续重评补丁中关闭。
- [ ] 重评前保存 stale/not_ready，实际校验 warning；重评后合法结果 pass。
- [ ] 原权限/数量文档矛盾不再作为仍存在的原文矛盾；新增日志缺口不能自行补业务规则。

依据：规格 7.2、RA-11；已审核第二样例 4.3。使用模型逐项比对，不写 compare_baseline.py。
