# RA-18：长期未更新的资料

## 输入

明确业务更新时间2020-01-01的合成旧架构草稿，固定as-of=2026-11-16、max-age-days=365。另由CLI测试覆盖未知日期和未来日期。

## 预设回答

无业务答案，不将mtime当业务更新时间，不将旧架构讨论当当前已确认能力。

## 核对清单

- [ ] 检索结果保留草稿权威、来源定位和指纹，返回过期复核warning。
- [ ] 不能从资料存在推导supported技术结论。
- [ ] 未知日期不编造；未来业务日期提示不可信。
- [ ] 年龄提醒不同于采用内容发生变化，不仅因为老旧自动改全部分析条目。

依据：规格8.3及RA-18，阈值明确可配置。
