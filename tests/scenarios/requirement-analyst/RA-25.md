# RA-25：过期分析门禁

## 输入

合法合成结果，analysis_status=stale；另用确定性测试覆盖 stale 与校验 fail 并存。

## 预设回答

先不坚持生成，随后模拟用户明确坚持使用过期分析（insist_stale=true）。这是测试开关，不代表真实用户已同意使用过期分析。

## 核对清单

- [ ] 默认返回 reevaluate，无草稿写入，提示先重新评估。
- [ ] 明确坚持才生成，status 保留 warning，草稿醒目标注“基于过期分析”。
- [ ] readiness 不因坚持而提高。
- [ ] fail 优先于 warning，即使坚持也拒绝生成。

依据：规格 10.2、RA-25。执行证据见 stage-4/attempt-02/RA-25。
