# RA-26：未就绪草稿

## 输入

通过唯一校验器的合成结果：analysis_status=completed、readiness=not_ready，仍有 open P0。

## 预设回答

模拟要求生成初步草稿，不提供业务答案。另运行 conditionally_ready 与 ready_for_document 分支作为门禁回归。

## 核对清单

- [ ] not_ready 只能生成明确标风险的初步草稿，open P0 保留。
- [ ] completed 不覆盖 readiness。
- [ ] 条件就绪列出遗留事项、暂定假设的依据与验证、研发确认项。
- [ ] ready_for_document 仍是待产品负责人确认的草稿，不执行发布。

依据：规格 6.7、10.2、RA-26。执行证据见 stage-4/attempt-02/RA-26 及 samples。
