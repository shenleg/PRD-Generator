# RA-17：采用资料变化与重评

## 输入

工作分析采用当前合成删除规范的实际指纹；资料第二版新增审计冻结禁止删除。旧版本另有不可变归档，旧发布分析快照只读。

## 预设回答

模拟资料第二版正式到达；先保存过期。内部重评后模拟产品确认两入口都保留未完成任务及冻结保护，不重新发布历史分析。

## 核对清单

- [ ] --check-sources只读检出adopted_sha256变化；旧索引排除变化正文。
- [ ] 实际new_source_version新增SRC，保存history_review=stale及stale/not_ready；warning不作ready。
- [ ] 原answered问题重开，保留旧answer并说明依据变化。
- [ ] 第二次supplement实际更新BR和间接AC、重新判定问题与清单，而非仅清除stale。
- [ ] 新旧来源均保留，旧基线指纹和归档不变；最终检查采用指纹一致。

依据：规格7.2、7.4、8.3、9.6；只读检测不是自动写状态，写入仍经唯一更新器。
