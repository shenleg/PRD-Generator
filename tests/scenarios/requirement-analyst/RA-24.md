# RA-24：缺少分析结果

## 输入

消费者收到生成草稿请求，但工作区或指定需求的 analysis-result.json 不存在。

## 预设回答

无业务回答。消费者只返回 action=analyze，交给需求分析入口；本场景不启动模型，也不伪造自动调用成功。

## 核对清单

- [ ] status=warning、written=false，不生成草稿或需求元数据。
- [ ] 不创建需求目录、不分配需求编号。
- [ ] 不从 analysis-report.md 或输入原文绕过分析直接生成。
