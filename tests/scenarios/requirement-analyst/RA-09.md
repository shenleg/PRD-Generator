# RA-09：补充引入新规则

验证目标：补丁只更新受影响部分，识别新边界或矛盾，不默默覆盖原规则。

## 输入

第二样例首次分析后的删除需求。模型只读取原文、当前结果、Skill 和本轮实际输入；不读参考要点或后续回答。

## 分轮预设回答

1. 实际问到旧删除规则后回答：“运行中的任务不能删除，其他的直接删，删了就找不回来了。”权限回答按 RA-05。
2. 检查补充引入的运行中/非运行中混选边界。
3. 在已有规则基础上追加：“补充一条：运行中的任务也要能从列表批量删除，但不能停止仿真。”仅为合成冲突探针，不代表真实业务决定。
