# RA-19：没有任何历史资料

## 输入

独立empty-workspace/no-history项目，无历史文件、无索引。当前只有一个合成功能想法。

## 预设回答

不补历史资料或业务答案，基本分析继续，核心缺口保留。

## 核对清单

- [ ] 检索warning说明缺索引，不伪造命中，不表示无冲突。
- [ ] 结果history_review=not_performed、source_ids=[]、baseline_revision=null。
- [ ] 对照脚本无baseline明确degraded，仍校验proposal合法性。
- [ ] 报告明示未做历史对照，不把没有历史当作分析失败或已完成全部核查。

依据：规格4.4、8.2与RA-19；与有资料项目隔离，不能用“未指定”冒充项目里没有资料。
