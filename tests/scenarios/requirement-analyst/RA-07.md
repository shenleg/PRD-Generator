# RA-07：用户回答不确定

验证目标：采用推荐项作为可追溯的暂定假设，不重复问。

## 输入及预设回答

共用 RA-05。首次提问到导出数量上限后，用户仅回答“不确定。”

## 核对清单

- [ ] 数量问题转 provisional，不记为 answered 或 risk_accepted。
- [ ] 对应 ASM 是 active，content 与上一轮真实推荐一致。
- [ ] 假设保留依据、验证人、验证途径及 related_question。
- [ ] 不把暂定数量写成已确认事实，也不再次要求用户回答同一数量问题。
- [ ] 其他未回答 P0 如实保留，不能因为这一题有假设就宣称全部已就绪。

依据：规格 6.3、6.4 与已审核第二样例 Q-c。
