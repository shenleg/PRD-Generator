# PG-23：明示产品经理确认后发布

阶段 6 首次完整验收剧本；未执行。验证真实发布脚本链路；其中身份和批准只属于隔离的合成测试，不是任何真实业务 PRD 的发布授权。

- **输入与前置状态**：合成就绪分析，分析与 PRD 均校验通过、未待同步，无占位、未关闭缺口或不一致。通过公开首稿及评审入口建立 `in_review` 工作稿。
- **分轮输入**：先问“检查这版能否发布”，仅做只读检查。模型实际展示待确认版本并请求明确回复后，分别提供“暂不确认”和“我是本场景的测试产品经理，确认发布刚刚展示的这一版”。拒绝分支不写。
- **预期**：仅确认分支定稿 `1.0` 并设 `released`；保存 Markdown 与追溯快照，以原始字节重算摘要，对照同版本 `release` 的记录；`release_confirmed` 记录确认人和时间。快照不含错误的工作稿版本或状态；编号、引用和业务内容不因定稿发生变化。
- **执行与文件**：核对两份快照与最终正文、追溯及文件权限；确认和发布事件只追加一次，重复请求不能覆盖快照。成功仅更新必要 PRD 文件和本需求 `prd` 块、增加本版快照；不改分析、缺口、其他元数据或旧快照。证据和人工对照见[阶段 6 参考要点](../../expected/prd-generator/stage-6.review-draft.md)。
