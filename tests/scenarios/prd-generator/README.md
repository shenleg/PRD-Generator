## 剧本写作要求

每份剧本包含输入、前置状态、逐轮用户回答、人工参考要点、允许和禁止的文件变化，以及证据保存方式。实际模型不可读取参考答案、预设后续回答或旧黄金输出。

阶段 0 的两组参考要点位于 `tests/expected/prd-generator/`，已于 `2026-11-17` 获本次用户明确认可；原始草案指纹及认可范围见 `tests/results/prd-generator/stage-0-decisions.json`。该认可不覆盖尚未编写的全部场景参考答案。后续正式剧本不得假造用户确认、就绪度或发布授权。
