# RA-05：逐步补充且不重复提问

验证目标：保持同次分析上下文，只更新受回答影响的内容。

## 输入

第二样例首次分析；首轮应优先删除权限、旧删除规则、导出上限三个 P0。

## 分轮预设回答

第 1 轮提问后，按问题语义回答：

- 权限：“以第 5 条为准，创建者和管理员可以删除，其他人只能看。”
- 删除规则：“运行中的任务不能删除，其他的直接删，删了就找不回来了。”
- 导出上限：“不确定。”

只有首轮实际问到对应问题时才提供该回答；未问到的问题不提前泄露。

## 核对清单

- [ ] 已回答权限和删除规则有 answer、user_answer 来源和正确状态。
- [ ] 不重新询问同一权限或运行中是否允许删除。
- [ ] 混合选择运行中与其他任务是新的边界，不被错误当成已经回答。
- [ ] 导出不确定的处理另按 RA-07 核对。
