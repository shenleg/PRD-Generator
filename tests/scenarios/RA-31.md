# RA-31：完成清单未满足

验证目标：清单不满足要登记对应问题，关闭问题不等于完成业务分析。

## 输入

复用第二样例原文及只有一句模糊想法的探针；另在确定性测试中使用问题均已关闭、但核心清单仍未满足的候选。

## 预设回答

不提供新的验收、核心规则或范围答案；用户要求直接出结果时按 RA-08 结束。

## 核对清单

- [ ] 每个独立需求核对全部十一项，未满足项有原因和本需求非 dropped 问题引用。
- [ ] 核心第 1～7 项未满足时有 P0，readiness=not_ready；第 8～11 项至少 P1且不能 ready_for_document。
- [ ] AC 草案为 inferred/to_reassess 时不能冒充可判定的完整核心验收。
- [ ] 清单缺失/重复/引用悬空，以及关闭问题后仍未满足却 ready 的候选被拦截。
- [ ] 完整语义判断另按已审核业务参考核对，不用 Schema pass 代替。

依据：规格 6.6、6.7、RA-31；已审核第二样例 T8 及两个样例的核心缺口。
