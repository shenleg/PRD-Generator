# RA-10：更正与撤销

验证目标：更正有明示证据，撤销保留历史，关联项正确重评。

## 输入

第二样例的导出暂定假设和通知需求当前结果。不能将这些预设回答提前混入首次分析。

## 分轮预设回答

1. 对导出数量问题答“不确定”，先按 RA-07 保存真实推荐所形成的 ASM。
2. 用户更正：“导出上限改成 5000 条。”
3. 用户撤销：“通知先不做了，本期去掉。”

## 核对清单

- [ ] 新数量为明示更正，旧 ASM 保留并撤销/待重评；旧推荐与用户原话可在事件中追溯。
- [ ] 数量相关规则和验收重评，其他未涉及内容保持。
- [ ] 通知 FR 保留且 withdrawn，关联问题 dropped，关联验收 to_reassess。
- [ ] 不删除通知需求目录或条目，编号不复用。
- [ ] 无用户明示的 inferred 覆盖 confirmed 补丁被拒，正式字节不变。
- [ ] 更正/撤销后的结果重新计算清单与就绪度，并通过统一校验。

依据：规格 7.2、9.3；已审核第二样例 4.1、4.2。不是要求整份需求完成就绪。
