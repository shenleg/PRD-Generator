# RA-13：价值分析从轻

验证目标：不索要无关收益论证，不重复问已明确原因。

## 输入

分别使用 `tests/fixtures/stage-2-probes/defect.md`、`notification.md`、`notification-with-reason.md`；均为明确标注的合成试验输入，不代表真实系统事实。

## 预设回答

只观察首轮：缺陷或原因已知时不补充价值信息；新增功能原因缺失时允许问一句原因，暂不回答。

## 核对清单

- [ ] 缺陷不要求业务价值、收益、频率等论证。
- [ ] 原因缺失的新增功能只问一句原因，不要求节省时间、错误率或收益数字。
- [ ] 已提供原因时不重复追问原因或强制补充价值数据。
- [ ] 没有输入的收益数字不出现在结果或报告中。

依据：规格 5.3 及已审核第二样例修订 5。
