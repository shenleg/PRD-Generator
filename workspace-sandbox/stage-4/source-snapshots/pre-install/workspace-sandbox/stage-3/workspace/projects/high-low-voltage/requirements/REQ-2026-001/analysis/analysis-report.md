## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P0 / ask_product / open**：这里一个“开关组合”的业务含义是什么？
  - 原因：这是组合生成的前置定义；原文同时出现开关动作和排列组合，不能自行解释成开/关二态全排列。本轮第1轮实际提出。；影响：决定tab中的候选项是什么，以及后续组合与设计表应表达状态还是动作。
  - 关联：FR-2、GAP-1、FLOW-1、AC-2
  - 选项：A. 一组开关各自所处状态的一种配置，不考虑动作顺序；B. 多个开关动作的先后顺序，顺序不同即不同组合；C. 业务预先定义的一套开关方案，不穷举所有配置或顺序；D. 其他，请说明；E. 暂不确定
  - 推荐：若目标是比较不同开关配置，推荐A作为讨论起点，先明确每个组合表示什么；A并不意味着每个开关只有两态，也不意味着所有配置都合法。若关心操作先后，应选B。用户选择前不采用任何解释。
- **Q-2 / P0 / ask_product / open**：两个tab里勾选的高压组合与低压组合，怎样共同决定要生成的结果？
  - 原因：仅有“根据勾选的高低压组合”不足以判断最终结果集合；不能默认跨压组合方式。本轮第1轮实际提出。；影响：不同规则会产生不同输出条目，错误理解会造成漏生成或多生成，核心生成逻辑无法验收。
  - 关联：FR-3、GAP-2、FLOW-1、AC-2
  - 选项：A. 每个选中高压组合与每个选中低压组合交叉配合；B. 由工程师明确指定高低压组合配对，只生成指定配对；C. 两类分别生成各自的结果，不做跨压配合；D. 其他，请说明；E. 暂不确定
  - 推荐：若设计表需要覆盖选中范围内的所有高低压搭配，推荐A，覆盖关系明确；若只允许特定业务搭配，B更合适。该推荐不是已确认的笛卡尔积规则。
- **Q-3 / P0 / ask_product / open**：生成的逻辑设计表，行、列与单元格分别应表达什么？
  - 原因：原文只命名了输出，未给表结构或正确结果样例；这是核心输出契约而非视觉细节。本轮第1轮实际提出。；影响：无法仅凭生成了一个表判断功能正确，也无法确定是否要求动作过程或其他结果信息。
  - 关联：FR-3、GAP-3、AC-2
  - 选项：A. 每行一个最终开关组合，每列一个开关，单元格记录该组合中该开关的状态；B. 按动作步骤逐行记录，展示操作对象及动作前后状态；C. 按已有业务模板输出，请提供模板或一份期望结果样例；D. 其他，请说明；E. 暂不确定
  - 推荐：若前面选择静态状态组合，推荐A作为最小可核对表结构，便于逐个组合检查开关状态；若选择动作顺序，B更匹配。若已有固定模板则优先C，不能自行发明模板字段。
- **Q-4 / P0 / ask_business / open**：在确认组合含义后，哪些开关状态或动作可用，哪些组合属于不合法输入？
  - 原因：原文未定义合法输入集合。此项依赖组合语义，先登记，未在本轮向用户提出。；影响：不能确定候选组合是否完整、是否含有不应使用的组合，以及非法输入的预期处理。
  - 关联：GAP-1、EXC-1、Q-1、AC-2
  - 选项：无交互选项
  - 推荐：先由业务提供可用状态或动作及约束依据；没有依据时不默认两态、不编造互锁，也不宣布全部配置合法。
- **Q-5 / P0 / ask_product / open**：图中无开关、仅存在一类开关，以及两类均未勾选或仅勾选一类时，生成动作应有什么可判定结果？
