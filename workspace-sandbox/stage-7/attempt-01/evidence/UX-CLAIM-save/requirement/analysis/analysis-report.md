## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P1 / lookup / open**：声称可沿用的批量撤回按钮和确认弹窗是否有对应画面或交互资料？
  - 原因：现有参考仅展示常态列表，未展示所声称的控件与弹窗。；影响：无法验证复用范围或设计已有流程。
  - 关联：FR-1
  - 选项：提供相关截图或原型；确认需新设计相关交互；其他或暂不确定
  - 推荐：建议先取得相关资料；在此之前不认定存在或不存在。
- **Q-2 / P0 / ask_product / open**：哪些失败项可以重试，重试时是否需要重新校验？
  - 原因：重试对象未定义。；影响：影响处理范围、权限及结果正确性。
  - 关联：FR-1
  - 选项：仅允许可恢复失败项重试并重新校验；允许全部失败项重新校验后尝试；其他或暂不确定
  - 推荐：建议区分可恢复失败并在重试时重新校验，范围由产品确定。
- **Q-3 / P0 / ask_product / open**：结果不明或已成功的项目再次提交时，是否允许重复生效？
  - 原因：重试是否重复生效未定义。；影响：可能重复改变业务数据，影响验收。
  - 关联：FR-1
  - 选项：不得重复生效并返回已有结果或状态；按明确业务规则重新执行；其他或暂不确定
  - 推荐：建议避免重复生效并明确结果不明时的处理；尚待产品确认。
- **Q-4 / P1 / ask_design / open**：结果、失败原因及重试状态如何呈现？
  - 原因：现有参考未给出失败或重试界面。；影响：影响用户理解和恢复操作。
  - 关联：FR-1
  - 选项：补充结果及重试状态低保真；补充交互文字说明；其他或暂不确定
  - 推荐：建议在规则明确后提供最小状态稿。
