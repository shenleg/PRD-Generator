## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P0 / ask_product / open**：批量选择允许覆盖哪些记录，筛选变化或跨页时选择范围如何计算？
  - 原因：选择范围及跨页行为尚未决定。；影响：直接决定实际处理对象，可能造成误操作或遗漏。
  - 关联：FR-1
  - 选项：仅允许选择当前页；允许跨页保留明确选择；允许选择全部筛选结果；其他或暂不确定
  - 推荐：建议先采用范围清晰的选择方案并明确展示对象数量，待产品确认。
- **Q-2 / P0 / ask_product / open**：对同一批次重复提交时应如何处理？
  - 原因：重复提交规则未定。；影响：影响是否重复执行及结果可验收性。
  - 关联：FR-1
  - 选项：阻止重复提交；允许提交但保证已处理项不重复生效；其他或暂不确定
  - 推荐：建议优先避免重复生效，并明确重复请求的反馈；具体规则待确认。
- **Q-3 / P0 / ask_product / open**：执行时申请不再处于待审批或创建人资格不满足时，该项如何反馈？
  - 原因：执行时状态变化结果尚未决定，但其他申请不得改变。；影响：影响逐条处理结果及权限边界验收。
  - 关联：FR-1
  - 选项：跳过该项并反馈原因；停止后续处理并反馈已有结果；其他或暂不确定
  - 推荐：建议在执行时重新校验且不改变不符合条件的申请，失败反馈方式待产品确认。
- **Q-4 / P1 / ask_design / open**：选择与逐项反馈应如何呈现？
  - 原因：参考仅有常态列表，缺少交互状态。；影响：影响操作可理解性。
  - 关联：FR-1
  - 选项：补充低保真关键状态；补充文字交互规格；其他或暂不确定
  - 推荐：建议先依据确认后的规则补充关键状态。
