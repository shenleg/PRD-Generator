# 门禁与资料降级

生成前调用 `scripts/check_gate.py`，以需求目录为位置参数；跨需求分析仅用 `--related-analysis` 显式提供，选项及调用细节以 `--help` 为准。过期时先展示结果、建议重新评估；用户明确坚持后才用 `--allow-stale` 重试。门禁复用分析校验，只读分析，不调用分析写入器。

| 结果 | 行动 |
| --- | --- |
| 缺分析、校验失败 | 拒绝生成，展示出错条目，建议回到分析 |
| 过期 | 优先于就绪度；仅用户坚持时生成 `stale_draft` |
| `not_ready` | `risk_draft`，仅供沟通 |
| `conditionally_ready` | `conditional_draft`，醒目列遗留事项 |
| `ready_for_document` | `formal_draft`，仍须后续确认 |

其他警告全部告知。信息缺失时不臆造、不因此中止；在文档信息的未覆盖分析项说明。价值评估缺省则省略背景与价值；技术评估缺省则不写技术结论，只列未答 `ask_dev`；`ui_dependent=false` 省略界面章节，`true` 但无视觉资料只列待设计事项；影响分析缺省省略相应章节，注明未包含历史需求对照。验收无 `related_ids` 时独立成节，不推断挂靠。辅助事件或来源清单不可读时，分别退化为条目比对或仅显示 `source_id`。

文首提示必须与类型一致：

- `risk_draft`：本文档基于未就绪的需求分析生成，存在未解决的阻塞问题，仅供沟通，不得作为开发或测试依据。
- `conditional_draft`：本文档存在待回答的问题和暂定假设，见“遗留事项”。
- `stale_draft`：本文档基于已过期的分析结果生成，内容可能与最新需求不符。
- `formal_draft`：草稿，待产品经理确认后发布。
