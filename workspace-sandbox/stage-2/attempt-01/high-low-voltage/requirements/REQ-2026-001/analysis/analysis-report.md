## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P0 / ask_product / open**：每个 tab 中的一个“组合”，业务上具体表示什么？
  - 原因：原文只说排列组合，没有定义组合的基本单位；不能直接假定每个开关只有开/关两态或穷举二进制排列。；影响：决定两个 tab 展示的对象、可选内容及后续生成逻辑，是其他规则的前置决策。
  - 关联：GAP-1、FR-2、FR-3、FR-4、AC-1
  - 选项：A. 一组开关各自的状态或动作赋值；请随选择说明允许的状态/动作取值。；B. 一组选中的开关成员，仅表示哪些开关参与，不表示状态或动作。；C. 已定义的命名工况；请提供一个工况包含哪些开关信息的例子。；D. 其他，请说明。；E. 暂不确定。
  - 推荐：推荐 A 作为讨论起点，因为背景提到“开关动作的逻辑设计表”，按开关逐项定义状态/动作更便于核对；具体取值仍须业务确认，不默认只有两态。
- **Q-2 / P0 / ask_product / open**：同时勾选多个高压组合和多个低压组合时，二者按什么关系生成结果？
  - 原因：原文未说明跨高低压类别的组合关系，不能自行推成全排列或按位置配对。；影响：决定生成哪些结果及结果条目的对应关系，关系不明会直接生成错误或缺失结果。
  - 关联：GAP-2、FR-5、BR-2、BND-2、AC-2
  - 选项：A. 每个已勾选高压组合与每个已勾选低压组合分别交叉配对。；B. 只生成用户明确指定的高压—低压配对。；C. 高压和低压分别输出，不进行跨类配对。；D. 其他，请说明。；E. 暂不确定。
  - 推荐：推荐 A 作为讨论起点：若目标是查看所勾选高低压组合的共同工况，交叉配对不需要额外隐含匹配规则；若业务只允许指定配对，应选 B。此推荐尚未采用，合法性筛选也未确定。
- **Q-3 / P0 / ask_product / open**：生成的“逻辑设计表”主要应表达哪一种业务结果？
  - 原因：未提供表结构或样例，仅知道生成表格不足以定义可判定输出。；影响：决定核心交付内容和验收基准；即使组合算法明确，仍可能生成不是工程师需要的表。
  - 关联：GAP-3、FR-5、AC-2
  - 选项：A. 组合状态表：每行一个完整组合，各开关的状态/动作作为列；请给出一行期望结果及最低必要字段。；B. 动作顺序表：每行一个切换步骤，体现开关动作及先后关系；请给出一个步骤样例和最低必要字段。；C. 沿用已有逻辑设计表格式；请提供表头及一行示例。；D. 其他，请说明并给出最低必要输出示例。；E. 暂不确定。
  - 推荐：推荐 A 作为讨论起点，因为它直接对应“勾选组合后生成表”；若现有手工表另有用途或固定格式，优先按真实样例修正，不能由分析者代定表头。
- **Q-4 / P0 / ask_product / open**：开关按什么业务依据归入高压或低压，不能归类的开关如何处理？
  - 原因：高低压划分在原文中明确存在，但划分标准未提供；无法归类的处理属于同一归类规则的必要边界。；影响：归类不明确会使输入错组或遗漏，两个 tab 的内容无法验收。
  - 关联：GAP-4、FR-1、FR-2、EXC-1、AC-1
  - 选项：A. 按业务已认可的高低压属性归类；属性缺失时提示补齐后再生成。；B. 按业务提供的开关类型映射归类；未覆盖类型提示补齐映射。；C. 由工程师明确指定归类；未指定时提示完成归类。；D. 其他，请说明。；E. 暂不确定。
  - 推荐：若已有权威属性，推荐 A，可避免重复维护归类规则；研发仍需核实该属性是否存在，不能把推荐视为当前能力。
- **Q-5 / P0 / ask_business / open**：可供选择或生成的组合，是否需要按业务合法性规则筛选？
  - 原因：原文没有说明组合是否全部有效，也没有给出互斥、联动等约束，不能自行决定合法集合。；影响：决定哪些组合可进入最终结果及其可判定预期；组合集合不确定则核心规则和验收不完整。
  - 关联：GAP-5、FR-2、FR-5、EXC-2、AC-1、AC-3
  - 选项：A. 所有按已定义取值构造的组合都有效，不另做合法性筛选。；B. 只允许满足业务规则的组合；需提供规则或有效/无效示例。；C. 由工程师维护可用组合清单，系统不自动判断业务合法性。；D. 其他，请说明。；E. 暂不确定。
  - 推荐：推荐 B 作为讨论起点：若表格用于工程逻辑设计，显式区分有效和无效组合可避免把错误组合作为可用结果；具体限制必须来自业务，不套用未提供的行业规则。
- **Q-6 / P0 / ask_product / open**：无开关、只有一类开关或存在零勾选时，生成行为采用什么空输入规则？
  - 原因：生成依赖勾选的高低压组合，但原文没有说明任一侧为空时的结果语义。；影响：决定空输入及单类场景能否完成核心流程，避免默认全选或静默生成不符合预期的表。
  - 关联：GAP-6、FR-1、FR-5、BND-1、BND-3、AC-3
  - 选项：A. 允许只有一侧有开关且有勾选时生成单侧结果；两侧均无有效勾选时不生成并提示。；B. 必须高、低压两侧都有有效勾选才生成，否则提示补齐。；C. 某侧未勾选表示采用该侧全部组合；没有任何开关时不生成。；D. 其他，请说明。；E. 暂不确定。
  - 推荐：推荐 A 作为讨论起点，避免将未勾选自动解释为全选，同时允许表达单类架构；若业务要求高低压成对才有意义，应选 B。尚未采用此规则。
