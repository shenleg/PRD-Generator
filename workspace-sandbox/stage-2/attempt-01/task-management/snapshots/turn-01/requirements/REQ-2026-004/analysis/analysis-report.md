- **Q-2 / P0 / ask_product / open**：请优先提供哪类可复现的状态错误样例？
  - 原因：有时候显示不对没有实际与预期行为。；影响：无法确定修复及回归边界。
  - 关联：FR-1、GAP-2、AC-1

- **Q-3 / P0 / ask_product / open**：实时允许的显示延迟如何验收？
  - 原因：技术更新机制不等于业务时间要求。；影响：核心实时要求不可验证。
  - 关联：NFR-1、GAP-3、BND-1
