  - 原因：常用条件缺少清单。；影响：无法确定核心输入和结果验收。
  - 关联：FR-1、GAP-1、AC-1

- **Q-2 / P0 / ask_product / open**：不同筛选条件如何组合？
  - 原因：组合和空条件语义影响同一输入的结果。；影响：不能唯一判定应显示的任务。
  - 关联：GAP-1、BND-1、AC-1

  - 推荐：推荐不同条件取交集、未选不限制，方便逐步缩小范围；仅为建议，尚未采用。
