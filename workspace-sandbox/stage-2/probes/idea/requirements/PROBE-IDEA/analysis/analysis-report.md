## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P0 / ask_product / open**：你说的逻辑设计表，首要表达的是什么？
  - 原因：术语未定义，不同含义会改变核心输出及后续规则。；影响：决定 FR-1 的输出语义，未确定前不能替用户选定状态模型或表格字段。
  - 关联：GAP-1、GOAL-1、FR-1、GAP-6
  - 选项：A. 开关状态组合与对应结果的关系表；B. 操作或事件条件与允许动作、联锁关系的规则表；C. 其他：请用一句话说明或提供一个表格片段；D. 暂不确定
  - 推荐：建议先以 A 为讨论起点，因为它能用一个状态到结果的例子较快澄清输入输出；这是帮助辨认表意的建议，不代表已确定为组合表或默认所有组合都合法。若你指的是操作条件与动作规则，应选 B。
- **Q-2 / P0 / ask_product / open**：首版优先服务哪个使用场景？
  - 原因：原文未说明核心用户和使用场景，无法确定首版工作环节。；影响：决定核心场景和结果使用方式，避免把设计、验证或现场操作需求混为一谈。
  - 关联：GAP-2、GOAL-1、CON-1
  - 选项：A. 设计人员编制或核对开关逻辑方案；B. 仿真或测试人员检查逻辑结果；C. 运行或操作人员查询操作条件；D. 其他：说明一个优先场景；E. 暂不确定
  - 推荐：推荐 A 作为首版讨论起点，因为原词是逻辑设计表，与编制或核对设计方案更直接对应；原文未确认用户身份，若主要用于仿真验证或操作查询，应分别选 B 或 C。
- **Q-3 / P0 / ask_product / open**：首版期望主要根据哪种业务输入生成表格？
  - 原因：没有生成依据，核心输入到输出流程无法还原。；影响：明确业务期望的数据入口；现有系统能否提供对应输入另由研发核查，不要求产品作实现承诺。
  - 关联：GAP-3、FR-1、CON-1、Q-8
  - 选项：A. 用户明确填写或配置的开关信息与逻辑规则；B. 用户导入的现有设计资料或规则表；C. 系统中已有项目、设备或连接关系数据；D. 其他：说明主要生成依据，可注明必要的组合；E. 暂不确定
  - 推荐：推荐先用 A 的方式描述一个小输入例子，因为可以直接讲清系统需要知道什么，不依赖尚未核实的现有数据或导入能力；这不是建议必须新增配置界面，若已有资料或系统数据才是期望依据，请选 B 或 C。
- **Q-4 / P0 / ask_business / open**：确定表格含义后，首版生成结果应遵循哪套业务规则？
  - 原因：规则及适用边界缺失，无法判断生成结果的合法性与完整性。；影响：决定合法结果、不适用情形及 BND-1 的处理，不能默认二态、全排列或自动联动。
  - 关联：GAP-4、BND-1、FR-1
  - 选项：A. 依据用户给定并确认的规则或设计标准生成；B. 依据本次需求新确定的规则生成；C. 其他：说明规则权威依据；D. 暂不确定
  - 推荐：若已有权威规则推荐 A，可沿可追溯依据确定合法输出；若不存在则选 B，由业务明确后再细化，不能自行补造。
- **Q-5 / P0 / ask_product / open**：输入依据不足或规则冲突、无法确定结果时，期望系统采取什么输出策略？
  - 原因：异常情况下的业务预期未知，自动生成可能给出无依据的结果。；影响：决定 EXC-1 的可判定行为，不把研发实现方式当作业务答案。
  - 关联：GAP-5、EXC-1、FR-1
  - 选项：A. 不生成正式结果，明确指出未满足的依据；B. 生成可判定部分，明确标记不可判定部分；C. 其他：说明希望的输出策略；D. 暂不确定
  - 推荐：推荐 A，避免把缺依据或矛盾结果误当作完整设计依据；若业务需要部分结果可选 B，再定义可判定与不可判定的边界。
- **Q-6 / P0 / ask_business / open**：首版用什么业务依据判定生成的表格正确且完整？
  - 原因：没有可判定预期，核心功能不可验收；不能把生成了一个表格当作验收完成。；影响：需要形成与已知输入、正常和关键边界相对应的预期输出，才能登记可执行 AC。
  - 关联：GAP-6、FR-1、Q-1、Q-4、Q-5
  - 选项：A. 提供已确认输入及对应正确样表作为对照；B. 由业务逐项确认字段含义和判定规则，再形成对照案例；C. 其他：说明可执行的正确性依据；D. 暂不确定
  - 推荐：有样表时推荐 A，能直观暴露输入、字段和规则缺口；没有样表时用 B，不要求用户虚构已有资料。
- **Q-7 / P1 / ask_product / open**：自动生成主要希望解决哪个现有问题？
  - 原因：新增功能原因未给出，只需补充一句主要痛点，不追加收益数字问卷。；影响：支持价值及必要性判断，但优先级低于当前核心定义和流程缺口。
  - 关联：GAP-7、GOAL-1
  - 选项：A. 减少手工编表；B. 减少逻辑遗漏或核对错误；C. 其他：说明主要痛点；D. 暂不确定
  - 推荐：推荐先从 A 核对，因为自动生成直接对应减少手工编制；若更关注正确性选 B。两者均未被原文确认。
