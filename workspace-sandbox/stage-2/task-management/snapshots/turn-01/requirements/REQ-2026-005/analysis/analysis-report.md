## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-1 / P0 / ask_product / open**：待导出结果超过1000条时，最终采用哪种数量规则？
  - 原因：1000条上限与大数据量导出全部直接影响输出。；影响：不裁决就无法确定截断、拒绝或全量导出，可能漏数据。
  - 关联：BR-1、BR-2、CNF-1、GAP-1、BND-1
  - 选项：始终最多1000条，超过时明确提示范围限制；必须完整导出，1000条不作为总量上限；每个文件最多1000条，允许分成多个文件并覆盖全部结果；其他（请说明）；暂不确定
  - 推荐：推荐每个文件最多1000条、分文件覆盖全部结果，作为兼顾两句原文的讨论起点；分文件是新增候选，不是原文事实，也未在确认前采用。
- **Q-2 / P0 / ask_product / open**：本期导出必须包含哪些字段？
  - 原因：常用字段没有清单。；影响：核心输出内容不可验收。
  - 关联：FR-1、GAP-2、AC-1
  - 选项：列出必需字段及含义；以旧报告字段清单为起点，确认本期字段；其他（请说明）；暂不确定
  - 推荐：推荐旧报告作对照后确认字段，符合延续诉求；报告取得前不编造字段。
- **Q-3 / P0 / lookup / open**：请提供之前的报告样例或格式说明。
  - 原因：要求保持一致但参考资料缺失。；影响：文件类型、列顺序、单位及格式不可核对。
  - 关联：BR-3、GAP-3、AC-1
  - 选项：无交互选项
  - 推荐：未填写推荐
- **Q-4 / P0 / ask_product / open**：一次导出的结果集合按什么范围确定？
  - 原因：全部结果可能指单任务、已选任务或筛选集合，记录粒度也未明确。；影响：范围不明会导错数据并改变计数口径。
  - 关联：GAP-4、BND-1、AC-1
  - 选项：单个任务的结果记录（请确认记录粒度）；选中任务的结果记录集合（请确认记录粒度）；当前筛选范围的结果记录集合（请确认记录粒度）；其他（请说明）；暂不确定
  - 推荐：推荐先明确单任务结果集合再讨论批量扩展，便于界定全部；尚未采用，不提前排除其他范围。
- **Q-5 / P0 / ask_product / open**：未能完整生成表格时如何认定本次导出？
  - 原因：不要丢数据需要覆盖部分失败。；影响：部分结果可能被误认为完整报表。
  - 关联：EXC-1、GAP-5
  - 选项：本次失败，不将部分文件作为完整结果交付；明确标记部分结果和缺失范围，允许重试补齐；其他（请说明）；暂不确定
  - 推荐：推荐整次失败并明确提示，避免误用不完整数据；是否保留部分结果另待确认。
