## 5. 待回答问题

下列是登记清单，不表示本轮继续提问；实际提问以 turn-NN.json 为准。

- **Q-4 / P0 / ask_product / open**：“全部结果明细及分页数据”具体指什么：需要导出所有明细行，还是还需包含分页元数据或按页面组织的内容？任务未完成时允许导出什么？
  - 原因：完整行集和触发时点直接决定核心输出及验收，现有原文无法确定。；影响：P0：决定导出范围、结果完整性及任务生命周期规则。
  - 关联：FR-1
  - 选项：仅在任务完成后导出该任务的全部明细行，分页仅作为读取方式；允许任务未完成时导出当前已有明细，并明确快照时点；除明细行外还导出分页元数据或按页面组织的内容，具体规则另行定义
  - 推荐：建议优先采用任务完成后导出全部明细行、分页仅作为读取方式；这是待产品确认的建议，不代表已有能力。
- **Q-5 / P0 / ask_product / open**：谁可以导出哪些任务的结果明细，是否需要跨项目访问？
  - 原因：需求中的“全部”尚不能确定是否仅指已授权任务内的全部明细；现有接口的访问范围不等于产品已决定的导出权限。；影响：P0：决定核心数据访问边界及安全验收，也会影响需验证的技术方案。
  - 关联：FR-1
  - 选项：仅允许在既有服务身份及已授权项目范围内导出；允许指定角色跨项目导出，并明确可访问项目范围；按任务或结果另行定义授权规则
  - 推荐：建议先限定在既有授权范围内，不默认跨项目；如业务确需跨项目，再由产品明确范围并由研发核验。
- **Q-6 / P1 / ask_product / open**：导出需要什么文件格式和字段，以及空结果时应返回什么？
  - 原因：需求只说导出明细及分页数据，没有指定输出格式、字段清单或空结果体验。；影响：P1：影响输出契约和验收细节；格式尚不能默认是CSV。
  - 关联：FR-1
  - 选项：使用CSV并明确字段及空结果文件规则；使用其他指定格式并明确字段及空结果响应；先确定必需字段和空结果行为，再选择格式
  - 推荐：建议先明确必需字段及空结果行为，再结合调用方需要选择格式。
